# Acceptance criteria — individual campaign

- [ ] All marketing copy, product/offer claims, URLs and compliance fields came from approved sources; gaps remain labeled.
- [ ] Asset slicing plan reviewed, true crops distinguished from edited/generated artwork, originals preserved.
- [ ] Required live heading/description/nutrition/CTA/legal content remains readable and actionable with images blocked.
- [ ] Any art composites contain only decorative elements or duplicate meaning available in live content.
- [ ] Each section's layout/crop/spacing compared to the actual reference; mismatch recorded rather than hidden.
- [ ] Editable source and compiled HTML deliverable present.
- [ ] Browser screenshots at 320, 390, ~600 and 1440 widths reviewed; no unexpected mobile horizontal scrolling.
- [ ] Build/validation results recorded with error/warning counts and compiled HTML byte size (plus transformed HTML bytes when available).
- [ ] `.txt` fallback prepared, actual ESP multipart plain-text alternative confirmed.
- [ ] Personalization tested with empty/long/unicode inputs; tracked links checked from test delivery.
- [ ] Source stack preserved unless change was approved; repeatable modules documented if added.
- [ ] Images and CTA links use final accessible hosting (HTTPS/ESP supported), with meaningful alt and fallback.
- [ ] Gmail/Apple Mail/Outlook inbox versions actually tested are named; untested clients explicitly reported.
- [ ] Dark mode, image blocking, Outlook-specific fallbacks and actionable links tested as required.
- [ ] Unsubscribe, legal sender details and merge tags confirmed for actual ESP/jurisdiction; not invented.
- [ ] Campaign owner has approved release. Do not mistake static lint/browser pass for production readiness.
