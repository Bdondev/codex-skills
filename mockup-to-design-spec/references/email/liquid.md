# Liquid / Shopify and other ESP dialects

Identify exact host and dialect (Shopify theme, Shopify Email, Braze, Customer.io, etc.). Theme Liquid objects are not automatically available in email. Verify supported objects, tags, filters, personalization and compliance links in the selected host. Document loop limits and missing values.

Documentation starting point: https://shopify.dev/docs/api/liquid
Verify current host-specific documentation; this reference is an audit checklist, not a compatibility guarantee.
