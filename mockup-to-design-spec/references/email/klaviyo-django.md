# Klaviyo Django-style

Klaviyo uses a platform-specific Django-style dialect, not a full Django runtime. Distinguish profile properties, event payloads and product feeds. Confirm campaign versus flow context, supported tags/filters and lookup syntax. Use native unsubscribe and preference mechanisms; test in Klaviyo with representative profiles/events.

Documentation starting point: https://developers.klaviyo.com/
Verify current host-specific documentation; this reference is an audit checklist, not a compatibility guarantee.
