# LiquidJS local or server rendering

LiquidJS is a JavaScript-hosted template engine, not JavaScript running in the inbox. Specify version, strictness, custom filters, synthetic JSON fixtures and output escaping. Use it for local previews or server-side rendering; do not assume parity with Shopify or ESP Liquid dialects.

Documentation starting point: https://liquidjs.com/
Verify current host-specific documentation; this reference is an audit checklist, not a compatibility guarantee.
