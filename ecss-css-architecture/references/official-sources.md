# Sources and scope

- [Efficient CSS methodology](https://ecss.info/en/) — primary source, selected values, principles and authoring rules. Not Ben Frain's Enduring CSS.
- [ECSS Stylelint preset](https://www.npmjs.com/package/@efficientcss/stylelint-config-ecss) — optional tooling linked by the methodology.
- [ECSS scaffolding](https://github.com/efficientcss/scaffolding) — starter linked by the methodology.
- [Tailwind compatibility](https://tailwindcss.com/docs/compatibility) — check the installed version.
- [Codex skills](https://developers.openai.com/codex/skills/) — installation and discovery conventions.

The platform adaptations, skill coordination, token examples and QA procedure are recommendations for this repository, not official ECSS requirements or certification. Native mode summarizes selected rules; the source remains authoritative for the full methodology. No official lint package was installed or tested.
